Be the Cell completion codes

Paste codes, one per line, or choose (or drop) a Canvas "Student analysis" CSV. Everything stays in this browser.

Check a run file

Choose a run file a student sent (be-the-cell-<level>-<variant>-a<attempt>.json). It is replayed here with the level's own rules, and its score and code are recomputed.

What a code cannot guarantee
  • Who played: there are no accounts, so a code can be passed on. Duplicate codes and duplicate variants are flagged; a unique code from someone else is not detectable.
  • An honest score: the checksum catches typos and casual edits, not a determined forger (the method is public).
  • A first attempt: clearing site data or using another browser starts again at attempt 1.
  • Re-checking without the run file: only a run file can be replayed, and a replay still does not show who made it.
  • Comparability across content versions: codes with different content versions may differ in variants or scoring.
